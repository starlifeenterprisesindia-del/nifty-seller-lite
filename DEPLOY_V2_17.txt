C. Optional permanent FII/DII cloud setup
1. Create a separate PRIVATE GitHub repository, for example:
   nifty-seller-private-data
2. Create a fine-grained personal access token restricted to that repository.
3. Give only repository Contents: Read and write permission.
4. In Streamlit: Manage app > Settings > Secrets, append:

[fii_dii_cloud]
owner = "YOUR_GITHUB_USERNAME"
repo = "nifty-seller-private-data"
token = "YOUR_FINE_GRAINED_TOKEN"
path = "fii_dii_15_sessions.json"
branch = "main"

5. Save Secrets and reboot once.
6. Open FII/DII journal. Status should show CLOUD + LOCAL SAFE.
7. Save one date or press Sync cloud now. The JSON file is created automatically.

Never put the token in GitHub code, screenshots or chat. Preserve existing [dhan] secrets.

D. Without cloud secrets
The app still works with local primary + mirror files and manual backup/restore, but a Streamlit deployment replacement can still remove local runtime data.

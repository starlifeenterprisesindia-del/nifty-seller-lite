Nifty Seller Lite 2.73.0 — Liquidity Magnet + Smart Entry Advisor

PURPOSE
- Adds a visible Money Concentration / Liquidity Magnet proxy inside Market Intelligence and Institutional Opportunity Window.
- Upgrades Premium Calculator -> Plan new entry into a simple one-glance Smart Entry Advisor.
- No One Brain strategy weights, decision thresholds, Execution Guard, Trade Plan, Position Guardian or Pressure Integrity formulas are changed.

LIQUIDITY MAGNET / MONEY CONCENTRATION
- Uses only option-chain data already present in the authoritative snapshot: OI, positive day OI change and volume.
- Compares visible concentration above spot (CE-side) vs below spot (PE-side).
- Output: UPSIDE / DOWNSIDE / BALANCED, 0-100 concentration scores, confidence and strongest visible strike/zone.
- It is explicitly a proxy: NOT exact rupee money, NOT private order flow, NOT proof of stop hunting.
- Institutional Window Path Clearance now uses magnet alignment as a bounded modifier.
- A strong opposite magnet prevents Institutional Window from upgrading to STRONG; OPEN remains possible only when all six gates still pass.
- Institutional Window alerts include Money Magnet context.

RECORDED DATA / REPLAY
- Money Concentration is stored automatically inside Market Intelligence -> Liquidity payload on every new snapshot.
- Market Intelligence Test Pack exports money_concentration_bias, upside/downside scores, primary strike/OI/OI-add/volume and confidence.
- Older evidence files can backfill the Money Concentration proxy from the option rows recorded at that exact timestamp; future outcomes are never inputs.
- calibration_summary.json now includes descriptive Money Concentration replay diagnostics.
- Replay rows now carry Money Concentration fields.

SMART ENTRY ADVISOR — PLAN NEW ENTRY
- New default one-glance view answers:
  1) current executable premium,
  2) preferred entry zone,
  3) acceptable entry zone,
  4) no-chase level,
  5) WAIT / ARMED / ENTRY CONDITIONS MET / FAST MOVE / NO CHASE / CANCEL status.
- Separates PRICE QUALITY from MOVE URGENCY so a perfect premium is not waited for when movement is genuinely accelerating.
- Move Urgency reuses existing Market Intelligence only: pressure, pressure quality, barrier attack, Institutional Window and Liquidity Magnet.
- W/M and Strong Candle remain supportive only and are never mandatory.
- SELL setups show current/preferred/minimum net credit with the selected protective hedge.
- Entry ladder is rebuilt around acceptable/preferred zones and never implies automatic averaging.
- Advanced detail remains available in a collapsed section so useful information is not removed.
- Already Entered mode stays focused on actual fill inputs and existing SL/target/P&L calculations.
- If Greeks are unavailable, the advisor can still show book/barrier context while future premium/SL-target projection remains safely blocked.

PERFORMANCE / SAFETY
- New Dhan/API calls: ZERO.
- Live Money Concentration benchmark on the recorded 30-row chain: ~6.9 ms average in build environment.
- Smart Entry Advisor synthetic benchmark: ~1.4 ms average in build environment.
- Protected One Brain files are byte-for-byte unchanged from v2.72.
- 24/24 automated tests PASS; full Python compile PASS.

NIFTY SELLER LITE 2.71.0_OBSERVABILITY_REPLAY_STATE_HARDENING

PURPOSE
-------
Improve reliability, measurable performance and post-market validation without changing
One Brain calculations, Pressure Integrity thresholds or broker/API usage.

LIVE-PATH CHANGES
-----------------
1. Snapshot Integrity diagnostic reads six existing FeedStatus objects only.
   - zero broker calls
   - zero One Brain weight
   - no stale value is converted into a vote
   - request-time feeds without source timestamps remain explicitly unknown-age

2. Performance panel now exposes:
   - latency budget GOOD/TIGHT/OVER BUDGET
   - top three slowest stages
   - existing P50/P95 session timing
   - evidence sync state

3. Big Player/activity state persistence now uses process-safe file locking plus the
   existing atomic temporary-file replace.

POST-MARKET / ON-DEMAND CHANGES
-------------------------------
4. Railway SQLite replay now carries recorded Market Intelligence fields:
   Move Radar, Pressure Quality, Move Attack/Risk, alignment, hunt and sync state.

5. Market Intelligence Test Pack adds:
   - calibration_summary.json
   - latency_summary.json
   These are descriptive diagnostics, not accuracy/win-rate/probability and never
   auto-tune thresholds.

6. Existing test-pack CSVs now carry snapshot sync fields when recorded by 2.71.

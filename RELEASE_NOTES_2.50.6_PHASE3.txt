Nifty Seller Lite 2.50.6_PHASE3_SMART_FOCUS

Phase 3 is presentation-only and follows the Golden Rule: no new broker/API calls,
no strategy recomputation, and no changes to the One-Brain critical decision path.

Changes
- Smart Focus added to Options Live Board using already-computed snapshot data.
  It marks ATM, CE/PE OI walls, wall clusters, and the current best protected
  strategy's main/hedge strikes.
- Optional NSL_PUBLIC_MODE=1 presentation mode added. It changes directive UI
  wording (for example TAKE NOW -> SETUP READY) without changing action keys,
  strategy calculations, journal data, or execution guards.
- App diagnostics now show INTERNAL vs PUBLIC SAFE presentation mode.
- Current internal mode remains the default.

Deferred
- IV Delta remains deferred until a near-zero-cost cached/asynchronous design is
  available. It is not added to the One-Brain calculation path in this release.

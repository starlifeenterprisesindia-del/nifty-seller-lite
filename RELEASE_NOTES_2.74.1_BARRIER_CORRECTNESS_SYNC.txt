Nifty Seller Lite v2.74.1 — Barrier Correctness Sync

PURPOSE
Harden barrier identity, promotion and break-side classification, then make sure the corrected barrier state reaches every existing consumer without adding broker/API calls or changing model weights.

CORRECTNESS CHANGES
1. Completed 3-minute close owns barrier promotion
   - Live spot remains the proximity/testing input.
   - A wick/tick above R1 or below S1 does not promote R2/S2.
   - The current barrier explicitly shows ABOVE/BELOW ZONE — AWAITING 3M CLOSE when appropriate.
   - Role reversal occurs only after a completed 3m close accepts beyond the full zone.

2. Full confluence zone is preserved
   - Structural/OI anchors are clustered first.
   - The completed close must clear the whole cluster boundary before that barrier is removed/promoted.
   - Individual anchors can no longer drop out while price is still inside the same confluence zone.

3. Break bias uses net vulnerability
   - Upside vulnerability = R1 Break Pressure - R1 Strength.
   - Downside vulnerability = S1 Break Pressure - S1 Strength.
   - Breakout bias compares those two values instead of raw break pressure alone.
   - Example fixed: R strength 90 / pressure 70 vs S strength 30 / pressure 65 now correctly reports DOWNSIDE RISK.

4. Reaction recency
   - Existing completed 1m touch/reaction history remains the source.
   - Recent reactions receive modestly higher weight; older reactions retain a floor weight.
   - UI wording now says completed 1m candles with ~3m reaction, matching the actual calculation.

A. Structural LevelBundle consumers automatically receive the completed-close role rule:
   - Canonical One Brain Barrier/Entry input
   - Trade-plan level clearance
   - Pattern nearest-level context
   - Pre-touch barriers
   - Any other module reading snapshot.levels

B. Enriched BarrierMap consumers automatically receive corrected barrier identity/bias:
   - Market Intelligence / breakout analysis
   - Pressure Integrity
   - Institutional Window path inputs through MI/Liquidity
   - Liquidity Intelligence / Liquidity Magnet path clearance
   - Big Player level reaction
   - Smart Entry Advisor / Strike Entry
   - SL/Target planner
   - Premium Calculator R1/R2/S1/S2 views
   - Live/compact barrier maps and chart
   - RSI reversal/strategy lab/evidence matrix/presentation safety
   - Replay, PDF, day memory, journal/export consumers

C. Market Intelligence breakout direction is explicitly synchronized with BarrierMap net vulnerability/breakout bias.

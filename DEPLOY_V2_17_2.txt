PERMANENT FII/DII — REQUIRED ONCE

1. Create a separate PRIVATE GitHub repository, e.g. nifty-seller-private-data.
2. Create a fine-grained token restricted only to that repository.
3. Give Repository permissions > Contents: Read and write.
4. Open Streamlit Manage app > Settings > Secrets.
5. Keep the existing [dhan] block and append:

[fii_dii_cloud]
owner = "YOUR_GITHUB_USERNAME"
repo = "nifty-seller-private-data"
token = "YOUR_FINE_GRAINED_TOKEN"
path = "fii_dii_15_sessions.json"
branch = "main"

9. Never commit/share the token.

NIFTY SELLER LITE — v2.75.0_LIVE_READABILITY_VALIDATION_HARDENING
Release purpose: correctness, validation, readability, alert-discipline and performance hardening after 09-Oct-2026 live forensic audit.

PERMANENT RULES PRESERVED
- One Brain remains the only operational decision authority.
- No retuning of One Brain market weights or live market scoring.
- Research floors remain direction >=54 and entry readiness >=62.
- Market Intelligence / Institutional Window / Liquidity remain advisory/shadow.
- Missing or stale evidence remains NO VOTE.
- FII/DII live direction weight remains 0.
- Barrier formulas/promotion rules remain unchanged; completed 3m close acceptance still controls promotion.
- No new live Dhan/broker API call was added for these features.

P0/P1 CORRECTNESS + VALIDATION FIXES
1. Decision Journal restart recovery
   - Railway/day-memory decision rows are merged back into the local Journal after deploy/restart.
   - UI shows SYNCING/WARMING while async recovery is pending instead of a false zero.

2. One Brain research sampler
   - Research lane evaluates the already-produced candidate_action while the live final_action can remain WAIT.
   - Live One Brain action is not loosened or changed.
   - Existing direction/entry/data/protected-plan guards remain required.

3. Market Intelligence research dedupe
   - Added persistent setup-cycle identity and sampled-cycle memory.
   - Cooldown alone can no longer create repeated paper trades from the same continuing setup.
   - Re-arm requires candidate disappearance/reset, direction/setup change or material barrier-zone change.

4. Paper validation completeness
   - Preserves MFE/MAE tracking and canonical close diagnosis.
   - Explicit exit reason and executable spread-price basis are persisted.
   - 5m/15m/30m later spot outcomes continue to backfill from authoritative later snapshots.

5. Evidence-recorder health presentation
   - Separates AVAILABLE, SYNC PENDING/WARMING, RETRYING and true UNAVAILABLE states.

PERFORMANCE
6. Instrument Master stale-while-revalidate
   - Live snapshot path immediately uses a valid stale cache and refreshes asynchronously.
   - First cold start can still perform the required blocking load.
   - Prevents repeated stale-master download waits on the market-critical path.

LIVE READABILITY / UI
7. Regime card
   - Long labels such as PULLBACK IN UPTREND wrap cleanly instead of truncating.

8. W/M + candle pattern emphasis
   - Strong bullish/bearish patterns receive direction-specific highlight.
   - Very-strong/confirmed-style states use a short finite pulse, not permanent flashing.

9. Bullish vs bearish evidence emphasis
   - Display-only dominance highlight based on already-calculated evidence.
   - Does not add or alter a One Brain vote.

10. Barrier break-readiness visuals
   - VULNERABLE: break pressure exceeds strength -> amber/static.
   - ATTACK: nearby barrier + existing Pressure Integrity attack evidence -> short directional pulse.
   - Confirmed break/role-reversal states -> solid emphasis.
   - Barrier calculation and 3m-close confirmation rules are unchanged.

11. Liquidity wording
   - User-facing “Liquidity Magnet” is presented as “Liquidity Concentration”.
   - UI explains it is observable OI/OI-addition/volume concentration, not a directional prediction or hidden-stop claim.
   - Internal historical field names remain backward compatible.

12. Main-route cleanup
   - Strategy + Strike Detail is always visible.
   - Live Chart is moved to More Tools & Advanced and defaults closed; chart calculation source is preserved.
   - One Brain Quick Guide is hidden from the operational screen; source remains available for future onboarding.

ALERT DISCIPLINE
13. Market Intelligence STRONG ONLY delivery
   - Lower-priority/watch events remain visible/recorded but are not sent as Telegram alerts.
   - Strong Window, verified attack, confirmed flip/sweep/failure and other material escalations remain eligible.
   - Story-level dedupe suppresses repeated messages from the same continuing direction/target story unless there is a critical escalation or direction flip.
   - Local delivery audit records SENT / APP_ONLY / SUPPRESSED and the reason.
   - Manual user-set premium alerts remain independent and unchanged.

CALCULATOR / IV
14. Large-lot calculator scenarios
   - Removed the arbitrary 100-lot input ceiling in calculation forms.
   - Calculator can compute above the live risk-profile lot cap and shows a clear warning.
   - Live execution/risk guard cap is NOT removed.

15. IV controls
   - AUTO IV — saved history: reuses persisted option history; no extra broker call.
   - MANUAL WHAT-IF: hypothetical IV delta only.
   - IV EFFECT OFF: disables IV adjustment in the what-if projection.

16. Smart Entry validation logging
   - Records current executable premium, best/acceptable/no-chase zones, urgency/action and context into a bounded local validation trace.
   - Uses existing calculated data only.

TOP-9 / COMPACT EVIDENCE
17. Top-9 freshness states
   - Keeps strict timestamp freshness; does not fake freshness.
   - Late-session stale constituents become REFERENCE/NO VOTE instead of looking like a broken 0/9 directional input.
   - Compact Evidence shows dashes/NO VOTE rather than Bull 0 / Bear 0 / Neutral 0 when unavailable.

18. Late-session spot presentation
   - When price progression is reference-only, UI explicitly distinguishes live options/futures from reference NIFTY spot progression.

RSI
19. RSI Top/Bottom strategy
   - Trading logic unchanged.
   - UI now clearly shows TOP ACTIVE / BOTTOM ACTIVE / NOT ACTIVE and the 15m RSI threshold reason.

Nifty Seller Lite v2.68.0_SMART_ALERT_COMPACT_UI

Purpose
- Reduce Telegram alert spam without changing any One Brain / Market Intelligence calculation.
- Fix Market Intelligence font truncation with responsive, wrapping UI cards.
- Keep GitHub upload package comfortably below 100 files.

Smart Alert delivery changes
- Market Intelligence alert lane now runs before the legacy candle/W-M/Big Player lane.
- Shared 3-minute setup cooldown prevents repeated same-direction Telegram messages.
- Big Player EARLY/CONFIRMED alone stays background evidence when Market Intelligence alerts are ON.
- Same-direction candle/Big Player confirmation is suppressed if a recent Market Intelligence alert already covers the setup.
- Direction flip, System Conflict, Liquidity Sweep and Build-up Failed can break cooldown when materially important.
- Mixed Pressure Acceleration is kept on-screen/recorded but normally suppressed from Telegram unless expansion pressure is unusually high.
- Market Intelligence Telegram message can include already-computed candle/Big Player confirmation in one compact combined story.

UI changes
- Market Intelligence main card uses responsive custom typography instead of truncating st.metric values.
- Long values wrap on desktop/mobile (e.g. EVENT-DRIVEN · MIXED, NO STRONG BUILD-UP, NO CLEAR VIEW).
- Advanced / Research detail remains unchanged and hidden by default.

Golden Rules
- No new Dhan/API calls.
- No changes to One Brain decision, Simple Brain, Future Brain, Entry/Execution Guard, Trade Plan, Position Guardian, Snapshot Service, Market Intelligence calculations or Liquidity calculations.
- Alert changes are delivery-only; all evidence remains available for journal/testing.
- UI changes are presentation-only.

Packaging
- Runtime analysis/services/ui modules are stored in nsl_runtime_v268.zip and loaded through Python zipimport.
- FULL_SOURCE_BACKUP_v2.68.0.zip is included so the complete editable source remains preserved.
